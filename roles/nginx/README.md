## Troubleshoot

Nginx logs are at `/var/log/nginx`.

### Domain name resolution might have a short stroke

It has happened that all services go away at the same time. This must be some instability on the network, but it eventually comes back.

If services are still available at their `IP:port` addresses, but unavailable at their domain names, only thing to do is a [queimada](https://en.wikipedia.org/wiki/Queimada_(drink)).
